## 项目简介

reTOdfa 是一个基于 Qt 的图形化应用程序，用于将正则表达式转换为等价的有限自动机。该工具支持正则表达式到 NFA（非确定性有限自动机）、DFA（确定性有限自动机）以及最小化 DFA 的转换过程。

## 功能特性

- **正则表达式解析**: 支持复杂的正则表达式语法，包括字符类、闭包、选择等操作
- **NFA 构建**: 将正则表达式转换为非确定性有限自动机
- **DFA 转换**: 将 NFA 转换为确定性有限自动机
- **DFA 最小化**: 对 DFA 进行最小化处理，获得最优化的自动机
- **可视化展示**: 图形化界面展示转换结果和状态转换表
- **文件操作**: 支持正则表达式文件的导入和处理
- **多语言支持**: 支持国际化，包含中文翻译

## 技术架构

### 核心算法

1. **正则表达式到 NFA 转换**
   - 使用 Thompson 构造算法
   - 支持基本字符、连接、选择、闭包操作
   - 处理字符类 `[a-z]`、`[0-9]` 等特殊语法
   - 支持转义字符处理

2. **NFA 到 DFA 转换**
   - 使用子集构造算法
   - 实现 ε-闭包计算
   - 状态转换表生成

3. **DFA 最小化**
   - 使用状态等价划分算法
   - 消除不可达状态
   - 合并等价状态

## 编译和运行

### 环境要求

- Qt 6.10 版本
- C++17 编译器
- MinGW或MSVC
- CMake 3.16+ 或 qmake

### 编译步骤

#### 使用 Qt Creator
1. 打开 `reTOdfa.pro` 文件
2. 配置构建套件
3. 点击构建按钮


## 使用方法

1. **启动应用程序**: 运行 reTOdfa 可执行文件
2. **输入正则表达式**: 在界面中输入或导入正则表达式
3. **执行转换**: 点击相应按钮执行 NFA、DFA 或最小化 DFA 转换
4. **查看结果**: 查看生成的状态转换表和图形化表示
5. **导出结果**: 可以导出转换结果用于进一步分析

## 支持的语法

### 基本操作符
- `.` - 连接操作（可省略）
- `|` - 选择操作（或）
- `*` - 闭包（零次或多次）
- `?` - 可选（零次或一次）
- `+` - 正闭包（一次或多次）

### 字符类
- `[abc]` - 字符集合
- `[a-z]` - 字符范围
- `[0-9]` - 数字范围

### 特殊字符
- `\*` - 转义的星号字符
- `\?` - 转义的问号字符  
- `\|` - 转义的竖线字符

### 示例
```
# 基本正则表达式
a*b
(a|b)*c
[0-9]+\.[0-9]+

# 命名定义
digit=[0-9]
letter=[a-zA-Z]
identifierB=letter(letter|digit)*
```

## 算法细节

### NFA 构造
使用 Thompson 构造法，为每个正则表达式操作符构建对应的 NFA 片段：
- 基本字符：两个状态，一个转换
- 连接：链接两个 NFA
- 选择：添加新的起始和终止状态
- 闭包：添加 ε-转换实现循环

### DFA 转换
通过子集构造法将 NFA 转换为 DFA：
1. 计算起始状态的 ε-闭包
2. 为每个输入符号计算新状态集合
3. 重复直到没有新状态产生

### DFA 最小化
使用等价状态划分算法：
1. 初始划分为接受状态和非接受状态
2. 递归划分不等价的状态
3. 合并等价状态
